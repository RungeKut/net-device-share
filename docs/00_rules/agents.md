# Правила работы с агентами

## Роли (модель — по цене задачи)

| Роль | Модель | Задача |
|---|---|---|
| Архитектор | дорогая | границы модулей, интерфейсы, риски; результат — документ в `docs/20_*/` |
| Аналитик | средняя | выписать факты в `docs/` (источник → документ) |
| Исполнитель | средняя | код по готовому заданию из `docs/`, сборка |
| Ревьюер | дорогая | независимая проверка diff |
| Поиск | дешёвая | «найти место в дереве, ответ в 5 строк» |

Короткий бриф с узкой целью работает лучше длинного сочинения: промпт
запускает модель по вектору и смотрит только по нему. Разные агенты с
разными промптами на одну задачу находят косяки друг у друга.

## Бриф субагенту (дословно)

```
Цель: <одно предложение>
Читай: <2–4 пути из docs/ и исходников>
Пиши: <пути результатов>
Не делай: <границы; необратимые действия — только с разрешения человека>
Правило комментариев: комментарии в коде запрещены по умолчанию —
комментарий должен доказать право на существование.
Ответ: ≤ 15 строк — сделано, пути, проблемы.
```

## Запреты

1. Не пересказывать агенту содержимое файлов — давать пути.
2. Не будить завершённого агента ради правки на 5 строк — пересчёт его
   контекста дороже новой задачи. Мелочь — верхнему агенту или новому
   короткому субагенту.
3. Исполнители не правят корневой `AGENTS.md`/`CLAUDE.md` и `STATE.md` —
   обновляет верхний агент после проверки.
4. Агенты не пушат и не выполняют необратимых действий без разрешения
   человека.
