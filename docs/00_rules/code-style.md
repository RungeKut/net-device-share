# Код

- Комментарии в проекте приняты: только «почему» (неочевидное решение,
  ограничение платформы, ловушка), не пересказ кода.
- Ноль зависимостей: `dependencies` в package.json пуст, не добавлять.
- Node.js >= 20.6, ES-модули, без шага сборки для запуска.
- Кодировки и переводы строк `start.bat` и PowerShell-скриптов не ломать
  (`sed -i` срезает CR); проверяет `npm run check`.
- Перед каждым коммитом: `npm run check` и `npm test`.
