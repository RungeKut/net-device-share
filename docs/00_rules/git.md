# Git

- Ветка `master`, remote `github` (публичный репозиторий).
- Один шаг — один коммит; push — только по команде человека.
- Автор коммитов — из `git config` репозитория; `--global` не менять.
- Сообщение коммита на русском; последняя строка:
  `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`
- Коммитить только свои пути (`git add <пути>`), не `-A`.
- Репозиторий публичный: адреса и имена внутренних серверов в файлы,
  сообщения коммитов и релизы не писать.
- Перед коммитом: `npm run check` и `npm test`.
