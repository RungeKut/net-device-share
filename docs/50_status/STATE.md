# Состояние (точка возобновления)

Обновлено: 2026-10-27

> Снимок, ≤ 6 КБ. История — в git, подробности — в docs/HANDOVER.md.

## Цель

Приложение (версия из git: тег vX.Y + число коммитов) работает в сети; шлюзы между сетями, туннели и общий мост — в master.

## Сделано

- Ревью «узлы не видят друг друга»: ответ на QUERY при неизменном состоянии; самолечение UDP (`needsRepair`/`repair`), счётчики отброшенного, предупреждение о клоне `nodeId`; круг соседа не скачет; кэш туннелей и `pulled` сбрасываются; шлюз отдаёт seed-у адрес его сети; 401 различает часы и ключ; битый `config.json` — копия `.bad-*`; брандмауэр `-IncludePublic`. Не сделано: сброс multicast при том же адресе, причина невидимости в UI. Живой проверки нет.
- Шлюз: метка «🌉 шлюз» у самого узла (шапка, «Узлы», владелец в каталоге) и у соседей. Автовыбор сетей берёт и адреса не из частных диапазонов (кроме 169.254), основной — частная: прямой кабель на 200.100.1.0/24 оставлял узел в одной сети. Шлюз никто не назначает: узел с живыми соседями минимум в двух сетях (`PeerRegistry.liveNetworks`) сам пересказывает каталог и объявляет `nets`; пропал сосед — звание уходит сразу, проверка сетей раз в 5 с (README, «Кто шлюз»). Живой проверки с отключением адаптера 200.100.1.1 не было — только тест.
- Обновление: обратный отсчёт (подтверждение 45 с, перезапуск, очередь) считает окно по меткам `trialUntil`/`graceUntil`/`eligibleAt`, тик меняет только текст (иначе терялся клик по «Обновить сейчас»). Пропажу сообщения у клиента по коду не воспроизвёл — нужны режим, фаза, лог узла.
- Скорость моста у соседей: `PeerRegistry._refreshBusy` считает занятым узел с `joins` (у карты в мосту `claim` нет). Тест гоняется для занятия и моста.
- Личная скорость держателей моста (`netShare.holderMeters`, `statsFor(deviceId, holderId)`), метрики и дашборд моста.
- Автозапуск службой от SYSTEM (задание `NetDeviceShare`, ACL-проверка, установщик «как службу»); закрепление соседей моста статическим ARP; очистка ARP на всех адаптерах; диалог адреса при подключении в мост.
- Раньше: шлюз, туннели TCP, обнаружение на всех интерфейсах, открытый круг (граница — достижимость порта), общий мост, подпись RPC v2, версия из git-тега, чек-лист `docs/REVIEW.md`, CI.

- `npm run check`: 100 инвариантов; `npm test`: 217 из 217 (2026-10-27, Node 24). Разовые падения metrics, net-traffic и e2e-обновления под нагрузкой — таймаут, отдельно проходят.
- Работает: каталог, группы, запросы, пароль, автозапуск, проброс USB (usbipd-win) и сетевой карты на Windows, вкладка «Сеть», самообновление на одной машине.

## Открытые вопросы

- Не проверено (HANDOVER, раздел 7): автозапуск от SYSTEM и установщик; Linux-бэкенд; байты живого USB; самообновление между разными компьютерами; «Копировать драйвер»; перенос IP настоящей карты, DHCP.
