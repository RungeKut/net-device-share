# Состояние (точка возобновления)

Обновлено: 2026-11-01

> Снимок, ≤ 6 КБ. История — в git, подробности — в docs/HANDOVER.md.

## Цель

Приложение (версия из git: тег vX.Y + число коммитов) работает в сети; шлюзы между сетями, туннели и общий мост — в master.

## Сделано

- По итогам ревью: BYE при живом пересказе шлюза не удаляет запись, а переводит на relay (узел за второй сетью не пропадает на полминуты); снимок отдаёт `_peerView` без внутренностей реестра; `_syncGateway` по составу живых сетей, не по числу; тест метрик — случайный discovery-порт.
- Ревью обнаружения (полный проход + стенд). «Сеть → авто» корректен (шлюз за ~5 с). Нога с живым broadcast и молчащим multicast вечно «ломалась» — ремонт глушил сеть; нога здорова при одном рабочем канале. Задвоение узла: дублей nodeId в реестре нет; источник — второй экземпляр на машине (selfMachine, «Задвоение узла» в настройках). Слышимость по сетям (lastHeardAt). Подсказка исключённых карт. Схема — docs/img/discovery-flow.svg.

- Нагрузочный стенд `scripts/loadtest.mjs` (таймеры ±15%). Замер на сервере — `docs/LOADTEST.md`: 200 узлов сошлись, 400 — нет (лавина TCP-запросов состояния; гипотеза), падение узла видят за 62–92 с, soak 160×60 мин чист.
- Ревью «узлы не видят друг друга»: QUERY отвечает всегда, самолечение UDP, счётчики отброшенного, клон `nodeId`, круг соседа не скачет, кэш туннелей сбрасывается, 401 различает часы и ключ, битый `config.json` — копия, брандмауэр `-IncludePublic`.
- Опрос COM/LPT/сетей: один PowerShell вместо двух, только при изменении (`DeviceHub._listSlow`); 20 узлов: 57% CPU → ~5%.
- Шлюз: метка «🌉 шлюз» у узла и соседей; автовыбор сетей берёт и не частные адреса (кроме 169.254). Звание по живым соседям минимум в двух сетях (`PeerRegistry.liveNetworks`), пропал сосед — уходит сразу.
- Автозапуск службой от SYSTEM; закрепление соседей моста статическим ARP; очистка ARP; диалог адреса при подключении в мост.
- Раньше: шлюз, туннели TCP, открытый круг, общий мост, отсчёт обновления и скорость моста у соседей, подпись RPC v2, версия из git-тега, `docs/REVIEW.md`, CI.

## Проверено

- Мост между настоящими сегментами (2026-10-22, три узла): занятие, адаптер, перенос адреса, ping до владельца работают. Переключение «сеть → авто» и шлюз — на стенде (2026-11-01, два узла на машине).
- `npm run check`: 110 инвариантов; `npm test` — 255 (2026-11-01, Node 24). Падения metrics, e2e под нагрузкой — таймаут.
- Работает: каталог, группы, запросы, пароль, автозапуск, проброс USB (usbipd-win) и сетевой карты на Windows, вкладка «Сеть», самообновление на одной машине.

## Открытые вопросы

- Не проверено (HANDOVER, раздел 7): автозапуск от SYSTEM; Linux-бэкенд; байты живого USB; самообновление между компьютерами; «Копировать драйвер»; перенос IP настоящей карты.
