## Цель

## Сделано

- I18n на 30 языков завершён (7 коммитов): ключевая схема (t(ключ, params) → язык → ru → ключ), словари src/ui/i18n/<код>.js — 30 файлов по 919 ключей в полном паритете (после топ-апа 25 srv-кодов и чистки мёртвых) (ключи, токены, непустота — тест i18n-keys), арабский rtl. Серверные сообщения кодами srv.*: fail(code, ru, params, extra) в core (e.code — legacy-слаг для статусов/тестов, e.srvCode — CAPS для перевода, LEGACY_FOR в fail.js), httpServer пробрасывает srvCode+params, статусы обновления — messageCode/phaseCode/params, блокировки COM — объекты {text, code, params}; клиент srv(err) с фолбэком на текст сервера, waitingCodes/waitingParams переведены. Ревью архитектора (docs/60_plans/i18n-review.md): три критичных находки (инертный srv, битые токены-выражения, коды без ключей) — исправлены.
- Нагрузка (замеры 11-12/11-13, стенд в `result/`, разбор в LOADTEST.md): 400 узлов — лавина TCP (kernel CPU 88,9%, 223 тыс. `connect ENOBUFS`) из-за неограниченного параллелизма `refreshPeerState`. Остановлена: очередь 12 одновременных (`stateConcurrency`) + откат 1→60 с по узлу со сбросом на успех (тест peers-state-limiter); замолчавший сосед (полтора анонса) проверяется `/peer/ping`, гистерезис — анонс во время ping отменяет пометку, офлайн со второй неудачи. Контрольный замер: шторм снят, но 400 узлов на одной машине всё ещё не сходятся — узкое место сместилось в квадратичную broadcast-сетку анонсов (экспонента 1,95).
- Слияние 2026-11-20: домашние коммиты (dea37c2 + 3, loadtest/limiter) смержены с непубликовавшейся локальной веткой i18n; конфликты — package.json (строка test — объединение), peers.js (конструктор), STATE.
- Обзор архитектуры (TARA) — docs/ARCHITECTURE-REVIEW.md: НФТ восстановлены и оценены 1–5, главные риски — O(N²) анонс-сетка, отставание живой проверки (HANDOVER-7), god-файлы ui/app+core/app; план из 7 пунктов (ADR по анонс-сетке — первый). Метод: TARA (habr 588392) + шаблон представлений (habr 907154).
- Правило пуша смягчено (AGENTS, решение человека 2026-11-20): агент пушит master сам при зелёных тестах и check; релизные теги/удаление/force — по-прежнему по команде. Master запушен в origin (i18n + слияние + обзор).

Диагностика без доступа к логам (они только для админа): шаг «Тесты» дублирует имена упавших тестов и ассерты в аннотации коммита (::error) — они читаются через API публично.
