Обновлено: 2026-10-27

## Цель

Приложение (версия из git: тег vX.Y + число коммитов) работает в сети; шлюзы между сетями, туннели и общий мост — в master.

## Сделано

- Ревью «узлы не видят друг друга»: ответ на QUERY при неизменном состоянии; самолечение UDP (`needsRepair`/`repair`), счётчики отброшенного, предупреждение о клоне `nodeId`; круг соседа не скачет; кэш туннелей и `pulled` сбрасываются; шлюз отдаёт seed-у адрес его сети; 401 различает часы и ключ; битый `config.json` — копия `.bad-*`; брандмауэр `-IncludePublic`. README: схемы и снимки в `docs/img`, раздел «Если узлы не видят друг друга». Не сделано: сброс multicast при том же адресе, причина невидимости в UI. Живой проверки нет.
- Опрос COM/LPT/сетей: один PowerShell вместо двух и только при изменении (отпечаток: реестр + интерфейсы, раз в 15 с; полное чтение ≈ раз в 5 мин, `DeviceHub._listSlow`, `slowStats`). Нагрузка: 20 узлов на машине съедали 57% CPU, стали ~5%. Подробности — ARCHITECTURE.
- Шлюз: метка «🌉 шлюз» у узла и соседей; автовыбор сетей берёт и не частные адреса (кроме 169.254). Звание по живым соседям минимум в двух сетях (`PeerRegistry.liveNetworks`), пропал сосед — уходит сразу, проверка раз в 5 с. Живой проверки с отключением адаптера не было.
- Обновление: обратный отсчёт (подтверждение 45 с, перезапуск, очередь) считает окно по меткам `trialUntil`/`graceUntil`/`eligibleAt`, тик меняет только текст (иначе терялся клик по «Обновить сейчас»). Пропажу сообщения у клиента по коду не воспроизвёл — нужны режим, фаза, лог узла.
- Скорость моста у соседей: `PeerRegistry._refreshBusy` считает занятым узел с `joins` (у карты в мосту `claim` нет). Тест гоняется для занятия и моста.
- Личная скорость держателей моста (`netShare.holderMeters`, `statsFor(deviceId, holderId)`), метрики и дашборд моста.
- Автозапуск службой от SYSTEM (задание `NetDeviceShare`, ACL-проверка, установщик «как службу»); закрепление соседей моста статическим ARP; очистка ARP на всех адаптерах; диалог адреса при подключении в мост.
- Раньше: шлюз, туннели TCP, обнаружение на всех интерфейсах, открытый круг (граница — достижимость порта), общий мост, подпись RPC v2, версия из git-тега, чек-лист `docs/REVIEW.md`, CI.

## Открытые вопросы

- Не проверено (HANDOVER, раздел 7): автозапуск от SYSTEM и установщик; Linux-бэкенд; байты живого USB; самообновление между разными компьютерами; «Копировать драйвер»; перенос IP настоящей карты, DHCP.
