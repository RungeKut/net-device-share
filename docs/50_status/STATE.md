## Цель

- I18n план: docs/60_plans/i18n.md — осталось: серверные сообщения кодами (srv.*), перевод на 28 языков, ревью, браузерный смоук en/de/ar.
- Узел за NAT: отражение не заводится в список, «чужая сеть», ключ маршрута адрес:порт|via. Ревью обнаружения, стенд loadtest (200 узлов сходятся, 400 — нет), ревью «не видят друг друга», опрос COM/LPT/сетей одним PowerShell по изменению.
- Шлюз: метка «🌉 шлюз», автовыбор сетей берёт и нечастные адреса, звание по живым соседям в двух сетях. Автозапуск службой от SYSTEM; статический ARP; мост, туннели TCP, открытый круг, общий мост, подпись RPC v2, версия из git-тега, CI.
