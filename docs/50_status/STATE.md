# Состояние (точка возобновления)

Обновлено: 2026-10-27

> Снимок, ≤ 6 КБ. История — в git, подробности — в docs/HANDOVER.md.

## Цель

Приложение (версия из git: тег vX.Y + число коммитов) работает в сети; шлюзы между сетями, туннели и общий мост — в master.

## Сделано

- Нагрузочный стенд `scripts/loadtest.mjs`, разброс таймеров ±15% (`timerJitter`). Замер на сервере (96 ядер, 256 ГБ, `result/`) разобран в `docs/LOADTEST.md`: 200 узлов сошлись, 400 — нет (похоже на лавину TCP-запросов состояния, не на UDP; гипотеза), падение узла видят за 62–92 с (30 с × 3 + 2), soak 160×60 мин чист.
- Ревью «узлы не видят друг друга»: QUERY отвечает всегда, самолечение UDP, счётчики отброшенного, клон `nodeId`, круг соседа не скачет, кэш туннелей сбрасывается, 401 различает часы и ключ, битый `config.json` — копия, брандмауэр `-IncludePublic`. README: схемы в `docs/img`. Не сделано: сброс multicast при том же адресе, причина невидимости в UI.
- Опрос COM/LPT/сетей: один PowerShell вместо двух, только при изменении (отпечаток раз в 15 с, полное чтение ≈ раз в 5 мин, `DeviceHub._listSlow`). 20 узлов: 57% CPU → ~5%; 100 узлов на 8 ГБ — предел по памяти.
- Шлюз: метка «🌉 шлюз» у узла и соседей; автовыбор сетей берёт и не частные адреса (кроме 169.254). Звание по живым соседям минимум в двух сетях (`PeerRegistry.liveNetworks`), пропал сосед — уходит сразу, проверка раз в 5 с.
- Обновление: обратный отсчёт (подтверждение 45 с, перезапуск, очередь) считает окно по меткам `trialUntil`/`graceUntil`/`eligibleAt`, тик меняет только текст (иначе терялся клик по «Обновить сейчас»).
- Скорость моста у соседей: `PeerRegistry._refreshBusy` считает занятым узел с `joins` (у карты в мосту `claim` нет). Тест гоняется для занятия и моста.
- Личная скорость держателей моста (`netShare.holderMeters`, `statsFor(deviceId, holderId)`), метрики и дашборд моста.
- Автозапуск службой от SYSTEM (задание `NetDeviceShare`, ACL-проверка, установщик «как службу»); закрепление соседей моста статическим ARP; очистка ARP на всех адаптерах; диалог адреса при подключении в мост.
- Раньше: шлюз, туннели TCP, открытый круг, общий мост, подпись RPC v2, версия из git-тега, `docs/REVIEW.md`, CI.

- `npm run check`: 106 инвариантов; `npm test` — см. ниже (2026-10-27, Node 24). Падения metrics, e2e под нагрузкой — таймаут.
