# Проброс COM и LPT: план работ

Составлен: 2026-11-01 (сессия ревью обнаружения, обсуждение с человеком).
Статус: план; выполнение — с чистого контекста, по этапам снизу вверх.
Ход работ отмечается в конце этого файла (раздел «Ход работ»).

## Цель

COM-порты узлов пробрасываются по сети с полным функционалом (байты, скорость,
линии управления, break); LPT — односторонний вывод. Бронь остаётся как режим
для того, что пробросить нельзя.

## Что уже есть (проверено, не переисследовать)

- Бронь COM/LPT: учёт держателя, аренда, heartbeat — `shareManager.js`; данные
  не переносятся. Занятие приходит по HTTP (`/api/v1/peer/claim`).
- Порты перечисляются в `devices/ports.js`; COM за USB-адаптером помечен
  `viaUsb` (InstanceId `USB\…`).
- Авторизованный TCP-канал с токенами и допуском по адресу:
  `net/tapLink.js` (`LinkServer`/`LinkClient`, порт `netLinkPort` 47814) —
  сейчас несёт кадры L2 для карт; байтовый режим ложится поверх той же
  механики.
- Установщики в `installers/` (`manifest.json`: sha256, подписант, sourceUrl,
  license; тихая установка; доустановка при запуске — `core/installer.js`,
  `scripts/fetch-installers.mjs`). Уже bundлятся GPL-компоненты
  (usbipd-win, usbip-win2 — GPL-3.0), приложение — MIT.
- usbip-win2 требует режим тестовой подписи (код 52) — принято человеком;
  com0com поедет в том же режиме.
- Решено с человеком: драйвер виртуального порта — **com0com** (GPL-2.0,
  официальные сборки: 2.2.2.0 fre-signed, 3.0.0.0 x64 без подписи; выбрать при
  добавлении). Драйвер не модифицируем: sourceUrl binaries + sourceUrl исходников
  того же релиза + license в manifest, COPYING рядом. LPT: вывод — да,
  двунаправленный EPP/ECP — вне плана (свой драйвер ядра).
- Ограничение: чистый Node не умеет SetCommState — параметры порта и линии
  задаёт хелпер, компилируемый на месте через PowerShell `Add-Type`
  (csc есть в системе; npm-зависимости не появляются).

## Этап A — подсказка «COM это USB-адаптер»

В каталоге и в карточке брони для COM с `viaUsb` показать: «Это USB-адаптер —
опубликуйте его как USB-устройство, и он пробросится целиком с портом COM у
клиента». Текст в `ui/app.js` (transportPill / место брони), признак уже в
мете. Проверка: руками на стенде; тест ui-ids не ломается.

## Этап B — канал байтов и насос владельца

1. `net/tapLink.js` (или рядом `serialLink.js`): байтовый режим существующего
   канала — длина-префикс, тип пакета (data | параметры | линии | break),
   токен и allowAddress как у карт.
2. Насос владельца: PowerShell `Add-Type` компилирует маленький C#-хелпер —
   открыть `\\.\COMx` с заданными baud/parity/стопами, читать/писать,
   сообщать линии (GetCommModemStatus) и принимать EscapeCommFunction/break.
   Компиляция и жизненный цикл — в `core/serialShare.js` по образцу
   `netShare.js` (grant/token, claim через существующий claim-поток).
3. Параметры порта запоминаются на время занятия (по образцу `netRestore` для
   карт), возвращаются при освобождении.
4. Тест без железа: автотест поднимает владельца и клиента на одной машине
   через пару com0com (если ещё не установлен — эмулировать насос парой
   пайпов в тесте); проверка эха и параметров.

## Этап C — клиентский com0com

1. `scripts/fetch-installers.mjs` + `installers/manifest.json`: сборка com0com
   (sha256, подписант, license GPL-2.0, sourceUrl binaries и исходников),
   COPYING в каталог компонента.
2. Установка пары портов и «адресной» привязки: наш мост открывает один из
   портов пары; у человека в «Диспетчере устройств» появляется COM с тем же
   именем, что у карты владельца (переименование через setupapi, как у TAP).
3. Занятие из UI: у COM вместо «Забронировать» появляется «Занять» с выбором
   параметров порта (или «как у владельца»).

## Этап D — устойчивость и документация

Переподключение канала (по образцу `tapLink` рестартов), буферизация при
паузе стороны, ошибки порта (отвалилась плата), лимиты скорости; README и
WINDOWS-SETUP (установка, подпись, сценарии). LPT-вывод тем же насосом
(`\\.\LPT1`, только запись) — за флагом, если дойдёт.

## Вне плана (осознанно)

Двунаправленный EPP/ECP LPT, другие ОС кроме Windows у клиента, платные
альтернативы com0com.
