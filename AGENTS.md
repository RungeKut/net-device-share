# Net Device Share

Совместный доступ к USB, COM, LPT и сетевым картам по сети. Node.js >= 20.6, v2.2.1.

## Инварианты

- Ноль зависимостей (`dependencies` пуст), `npm install` не нужен.
- Без шага сборки для запуска: `node src/main.js`.
- Репозиторий публичный (GitHub): адреса и имена внутренних серверов не писать.
- Ветка master, remote github; push только по команде человека.

## Карта

- `docs/50_status/STATE.md` — читать первым
- `docs/INDEX.md` — какой файл когда
- `docs/00_rules/` — правила процесса

## Правила

1. Сессия ~100-200К; шаг = коммит + STATE.md.
2. Документы - справочник; ссылки вместо копий. Большие (ARCHITECTURE, PROTOCOL, UPDATE, HANDOVER, METRICS, WINDOWS-SETUP) не делить.
3. Комментарии - только «почему».
4. Бриф агенту по `docs/00_rules/agents.md`; ответ <= 15 строк.
5. Необратимое (push, удаление) - с разрешения человека.
6. Исполнители не правят этот файл и STATE.md.
7. GUI - только на скрытом столе (скилл hidden-desktop).

## Команды

- запуск: `npm start` (отладка: `npm run dev`)
- `npm run check` - файловые инварианты
- `npm test` - тесты
