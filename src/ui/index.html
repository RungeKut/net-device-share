Устройства и группы, доступные в сети

Устройства этого компьютера

Опубликованное устройство видно другим узлам. Занять его может любой из них — и вы сами. В поле «для чего» напишите, что это за устройство: этот текст видят все.

Группы устройств

Группа — составное устройство. Для отладки платы нужны JTAG и COM сразу, и занимать их по отдельности бессмысленно: между двумя захватами вклинится кто-то третий. Группа занимается целиком.

Занято этим компьютером

Устройства с пробросом присутствуют в «Диспетчере устройств» так же, как подключённые кабелем. Остальные только числятся за вами — их вы подключаете физически.

      Общий ключ сети (обязателен для работы между сетями)
      

        
        
        
      

      Годятся любые печатаемые символы, не короче 8; пробелы по краям отбрасываются —
        они невидимы, а из-за них узлы молча перестают видеть друг друга. Сравнивается
        посимвольно, поэтому на всех компьютерах ключ должен совпадать в точности.
        Кнопка даёт 125 случайных бит без похожих друг на друга знаков (без O и 0, I и 1),
        так что его можно продиктовать. Узлы с разными ключами не видят друг друга.
        Изменение требует перезапуска.
      

    


    

      
      
    


    

      
      
    


    

      Узлы в других сетях

      
Обнаружение по UDP не выходит за пределы подсети: broadcast не
        маршрутизируется, multicast в корпоративных сетях обычно тоже. Укажите здесь адрес
        одного узла из другой сети — приложения обменяются списками и расскажут о них своим
        соседям. Настроить достаточно одну сторону.


      

      

        
        
      


      

    


    

      Темп анонсов

      
Анонс присутствия получает каждый компьютер подсети. Пока состояние
        меняется, узел объявляется часто; в покое интервал сам растёт до медленного и трафик
        падает на порядок. Любое изменение мгновенно возвращает быстрый темп.
