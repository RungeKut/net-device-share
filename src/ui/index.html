Устройства и группы, доступные в сети

Устройства этого компьютера

Опубликованное устройство видно другим узлам. Занять его может любой из них — и вы сами. В поле «для чего» напишите, что это за устройство: этот текст видят все.

Группы устройств

Группа — составное устройство. Для отладки платы нужны JTAG и COM сразу, и занимать их по отдельности бессмысленно: между двумя захватами вклинится кто-то третий. Группа занимается целиком.

Занято этим компьютером

Устройства с пробросом присутствуют в «Диспетчере устройств» так же, как подключённые кабелем. Остальные только числятся за вами — их вы подключаете физически.
